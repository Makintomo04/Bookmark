# Hardcover feature inventory (compiled from observed pages, 2026-10-27)
Each line cites the scrape file holding the source URL + quote.

- Statuses: Want to Read, Currently Reading, Read, Did Not Finish (renamed from "Stopped"), Paused (added Aug 2026); "Not interested" (roadmap Released). No custom statuses (lists instead). [homepage.md, changelog.md Aug 2026, roadmap.md]
- Ratings: half-star increments, 0.5–5 [homepage.md, goodreads-vs-hardcover.md]. Quarter stars: not observed.
- Reviews: rich-text/markdown editor, spoiler marks, @-mentions, likes, report, delete [changelog Jul 2026, book-page-and-seo.md]
- Progress & journal: page/% progress, reading journal (notes, quotes at % point, progress entries), all-entries view; reading streaks / Reading Activity widget [changelog Oct/Sep/Jul 2026]
- Dates: multiple reads, year-or-month-only finish dates, timezone aware [changelog Apr 2026]
- Stats: reading stats free; "Stats for any Date Range" Supporter-only; 18 chart types; reading format pie (audiobook colour); clickable stats [pricing.md, changelog Apr/Sep 2026]
- Year in review: personal "Wrapped" (2025) + community "Year in Books" (2023–2025) [blog.md, changelog Feb 2026]
- Goals: multiple goals, books/pages/hours; progress-based [goodreads-vs-hardcover.md, changelog Oct 2026]
- Lists: unlimited, ranked, prompt lists, Filter Lists (hide/label, subscribable), Collaborative Lists (Supporter-only owner), bulk edit (Supporter) [pricing.md, changelog]
- Prompts: community polls ("Prompts are polls"), monthly Featured Prompt [blog.md]
- Imports: Goodreads CSV, StoryGraph CSV, custom CSV (beta), library reset; Export: JSON (per 2022 comparison; a 2025 Play review complains about JSON export) [faq.md, goodreads-vs-hardcover.md, apps.md]
- Recommendations: Vibes (two-tower model, 256-d taste space, in-house, no external LLM); Similar Books; Discover page; free vs Supporter split [changelog Aug/Sep 2026]
- Taxonomy: genres, moods, content warnings, custom tags (community-voted, librarian-lockable; can be marked spoiler); Audience incl. "spicy reads" as Vibe signal; literary-type pill fiction/nonfiction. Dedicated spice/trope rating: not observed (App Store review requested it) [book-page-and-seo.md, changelog Jun 2026, apps.md]
- Series: series pages, Series Tracker (Labs), follow series, sort by next release, omnibus/partial books [changelog Feb/Mar 2026]
- Following: readers + authors, series, books, editions, characters, publishers (public follows) [changelog Feb 2026]
- Release alerts: "Book release notification" = Planned on roadmap (not shipped) [roadmap.md]
- Social: follow (one-way), feed, For You feed, likes, mentions, "inspired reads", profile Similar Reads; no DMs (2022 comparison); feed comments under consideration [roadmap.md, faq.md]
- Community (in alpha/beta Oct 2026): Book Clubs, Buddy Reads, Posts/Discussions, Events, Locations, ranked-choice polls, club Most Wanted + club Vibes recs, invite links, Network tab [changelog Oct/Sep 2026; roadmap "Limited User Rollout"]
- Spoilers: spoiler text in reviews; spoiler-tagged tags; content warnings hidden behind Reveal [changelog Aug 2026, book page]
- Privacy: per-book Public / Following / Private; lists & goals same [faq.md]
- Audiobooks: reading format per edition, hours listened, audiobook goals, Audible ASIN lookups (all regions) [changelog]
- Editions: book vs edition model; choose edition per read; country flags; edition merges/splits [faq.md]
- Dashboards: customisable widgets; multiple dashboards Supporter-only [changelog Mar/Apr 2026]
- Data editing: community + librarians + Supporters (paid edit access) [librarians.md]
- API: public GraphQL, PAT + OAuth, 5k/50k daily, TS SDK; commercial tier planned; no LLM training clause [api.md]
- Integrations: community-built only (KOReader, Kobo NickelHardcover, Audiobookshelf, Obsidian, MCP servers...) [integrations-showcase.md]
- Apps: iOS + Android ("effectively a wrapper for the website", Nov 2025); native iOS push/widgets "in the works" (Jun 2026) [apps.md, metrics-timeline.md]
- Theme: light/dark/system [changelog Jul 2026]
- Referrals: 2 referrals = 1 free Supporter month [faq.md]
- Monetisation besides Supporter: Bookshop.org + Amazon affiliate-tagged buy links on book pages; future "carefully designed book promotion" for authors [book-page-and-seo.md, faq.md]
- Author profiles/claiming: not available; in research (survey) [faq.md, changelog Aug 2026]
