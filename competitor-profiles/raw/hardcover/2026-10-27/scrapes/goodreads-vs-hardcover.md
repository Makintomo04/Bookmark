# Goodreads vs. Hardcover: Which is Right for You? (Hardcover comparison page)
Source: https://hardcover.app/blog/goodreads-vs-hardcover (linked from homepage "See how we compare")
Fetched: 2026-10-27. Byline date 09/07/2022 (Adam Fortuna), but table has been partially updated since (mentions "2.5 years" age, "2023 Year in Books", recommendations "target: Q1 2026") — mixed-date content; treat details as possibly stale.

Comparison table (Hardcover column):
- Year founded 2021; Owner: "100% employee-owned" (Goodreads: Amazon)
- Public API: GraphQL API (Goodreads: deprecated REST)
- Data export: JSON; "Google Sheets/Airtable sync on the roadmap" (Goodreads: CSV)
- Statuses: Want to Read, Currently Reading, Read, Did not Finish (no custom statuses; lists instead). [Paused added Aug 2026 per report]
- Personal tracking: dates started/finished, private notes, edition, ownership, reading format (audio, text)
- Lists: status, manual, ranked, prompt lists; custom columns; table/shelf/card views; list stats; filter by genre/mood/content warning/custom tag; group by; drag-and-drop; per-list settings
- Ratings: "0.5 – 5 stars (with half stars)"; reviews with custom editor for spoilers
- Social: follow readers, followers feed, For You feed (no 2-way friends listed)
- Privacy: profile public / followers only / only you; book activity public / followers / private; lists same
- Recommendations: "Rebuilding this feature, target: Q1 2026" (since shipped as Vibes, Aug 2026)
- Notifications yes; **Direct Messaging: no**
- Discoverability: feed, lists, prompts, trending, by genre/mood/tag
- Book database: "Backed by external APIs, our librarians & the community"
- Taxonomy: flat ranked genres; content warning tags; mood tags; custom tags; all can be marked as spoiler
- Community: social feed, prompts, Discord; "We're working on discussions next!" (Goodreads listed with Book Clubs, Groups, Discussions, Ask an author, Trivia, Quizzes)
- Stats: list stats, reader stats, year in review, Year in Books
- Goals: "Multiple date-based goals; By pages read or number of books"
- Apps: website, mobile web, iOS & Android apps
- Book vs edition model: status set on the book, edition optional; reviews aggregated across editions.
